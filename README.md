# Internship Tasks

This repository is dedicated to internship tasks and project assignments.

## Workflow & Git Guidelines

- **Branching Rule**: Each task must be done in a separate branch different from `main` (e.g., `task-1`, `task-2`, or `feature/task-X`).
- **Protected Main Branch**: The `main` branch is protected. Direct commits or pushes to `main` are restricted.
- **Pull Requests**: All completed tasks must be submitted via a Pull Request (PR) targeting `main` for code review and approval before merging.

## Tasks Directory

- **[Task 1: Library Management System API](./task1/README.md)**: Django-based Library Management System featuring custom user authentication, role-based access control, book inventory, borrowing workflows with admin approval, and author-submitted books.
